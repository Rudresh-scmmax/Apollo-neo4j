WHAT IS SHACL?

SHACL (Shapes Constraint Language) is a W3C standard for defining and validating the structure of RDF graph data. Apollo uses SHACL as an automated Data Quality Guardian — every node in the Knowledge Graph is validated against a set of shape rules before it can be queried by the AI assistant.
